# TourneyHub Web SPA

This is the minimal frontend SPA for TourneyHub, built with React, Vite, TypeScript, and Tailwind CSS.

## Commands

- `npm install` - Install dependencies
- `npm run dev` - Start the local development server
- `npm run gen:api` - Generate typed API client schemas from the OpenAPI contract (`../api/openapi.yaml`)
- `npm run typecheck` - Run TypeScript compiler checks
- `npm run lint` - Run ESLint
- `npm run build` - Build for production
